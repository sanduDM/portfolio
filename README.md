# Sandunika Dissanayake — React Portfolio

A responsive React + Vite portfolio designed around the 10-mark portfolio evaluation rubric.

## Run
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Before submission
- Replace `YOUR_EMAIL@example.com` in `src/main.jsx`.
- Replace `YOUR_LINKEDIN_URL`.
- Add your real CV as `public/Sandunika-Dissanayake-CV.pdf`.
- Replace placeholder GitHub project URLs with the actual repository URLs.
- Add your real school name.
- Add verified certificates/awards and project screenshots if available.
- Test all links and run `npm run build`.

## Rubric coverage
Home, About, Skills, Projects, Education, Experience, Certifications & Achievements, Resume/CV, Contact, responsive/modern UI.
